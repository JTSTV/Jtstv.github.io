# 本站官方博客 GitHub 源文件
> 发布日期：2036‑08‑22
> ✨ 源码体积不足1k，极致轻量化

项目仓库地址：<https://github.com/JTSTV/Jtstv.github.io>

本博客主打**极简清爽**的设计理念，追求网页极速加载的访问体验。

## 博文撰写方式
写博客的操作十分便捷，不同设备均可快速上手：

- **苹果手机**：安装 GitHub 客户端，进入 `_post` 文件夹新建文档。自定义填写文章标题与正文内容，内容也可以为空，完成后直接提交即可发布。
- **安卓手机**：直接通过网页端即可完成全部编辑提交操作。

## 项目特点
- 源码体积不足1k，极致轻量化
- 不需要部署数据库，几乎零维护成本
- 整体风格干净朴素，仅由少量文件组成，即可搭建属于自己的个人博客
- 内置网站地图，方便内容检索
- 主页提供邮箱入口，欢迎大家前来技术交流
